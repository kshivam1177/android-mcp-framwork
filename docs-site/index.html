AndroidBuildMCP is an MCP server and CLI for helping coding agents discover Android projects, work with Gradle, manage devices, inspect app UI, diagnose failures and build evidence-oriented test workflows.

Capabilities

One interface for agent-assisted Android work

Build and diagnose

Discover project structure, work with Gradle builds, and inspect logs and crash diagnostics.

Inspect and interact

Work with Android devices, UI hierarchy, screenshots, gestures and text input through available tools.

Test intelligence

Analyze code changes, validate structured test plans, resolve scoped instructions and write redacted test reports.

Agent-friendly setup

Use the MCP interface from compatible coding agents. See the repository guides for client-specific setup.

Run from source

Get started

Prerequisites: Node.js 18 or newer, Android SDK Platform Tools (adb), and Gradle for Gradle-based projects. Device operations require a connected device or emulator.

git clone https://github.com/kshivam1177/android-build-mcp.git
cd android-build-mcp
npm ci
npm run build
npm test
node build/cli/index.js mcp

The npm package and one-command install will be announced after package ownership, clean-install verification, automated tests and release configuration are complete. Until then, run from source.

Project status

Built in the open

The project is under active development. Some test-intelligence features are planning and reporting utilities rather than an autonomous end-to-end runner. Review the current source and documentation before relying on a workflow in CI or production.
